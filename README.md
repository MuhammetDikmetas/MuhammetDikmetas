## 🚀 Featured projects

### 🏦 [Triagent](https://github.com/MuhammetDikmetas/triagent-turkish-banking) · KVKK-aware AI triage agent for Turkish banking

Classifies Turkish customer messages into 8 banking categories and 3 urgency levels, routes them to the right team and drafts a reply that a human agent must approve.

- 🔒 Masks T.C. Kimlik No, IBAN and card numbers **locally** with checksum validation (TCKN, mod-97, Luhn) before any text reaches an LLM
- ⚡ Hybrid routing: a CPU classifier handles confident cases, Claude handles the rest → **94.4% accuracy with 61% fewer LLM calls** than LLM-only
- 👤 LangGraph workflow with human-in-the-loop approval · FastAPI backend · web console · CI with GitHub Actions

`LangGraph` `Claude` `scikit-learn` `FastAPI` `Pydantic` `pytest`

### 📄 [TR-Docuquery](https://github.com/MuhammetDikmetas/TR-Docuquery) · TÜBİTAK 2209-A supported research project

Intelligent document management system that combines OCR and RAG for natural-language querying of Turkish documents. I built the semantic search layer with embedding models and a vector database.

`OCR` `RAG` `Embeddings` `Vector DB` `LLM`
